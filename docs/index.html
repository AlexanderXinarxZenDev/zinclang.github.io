Welcome to ZincLang

A modern, statically‑typed language that runs on the JVM.
Import any Java library, write clean code, and run it everywhere.

⬇️ Download for Windows (Portable .exe)

🧩 Seamless Java Interop

Use any Java class directly: import java.util.ArrayList; – no wrappers, no FFI.

📦 Dynamic Modules

Import Zinc modules (.zc) as namespaces. Export functions, variables, classes.

🚀 Portable .exe (Windows)

One‑click executable bundled with a minimal JRE. No Java installation required.

🎯 Strong Typing

int x = 10; · float pi = 3.14; · bool flag = True;

🔄 Python‑inspired Syntax

if/else, while, for, break, continue – familiar and readable.

📚 Built‑in I/O

Print("Hello") · Input("Name: ")

📦 Installation (Windows Portable)

Option 1 – Download the .exe (recommended for users)

  1. Go to GitHub Releases.
  2. Download the latest ZincLang.exe (packaged with a JRE).
  3. Place it in any folder – no installation needed.
  4. Double‑click to start the REPL, or run from terminal: ZincLang.exe myscript.zc.

No Java required! The executable includes everything.

Option 2 – Build from source (for developers)

git clone https://github.com/AlexanderXinarxZenDev/ZincLang.git
cd ZincLang
javac -d classes zinc\*.java
java -cp classes zinc.ZincLang

Requires JDK 17+.

✨ First Zinc program

// hello.zc
Print("Hello, ZincLang!");

int x = 10;
if (x > 5) {
    Print("x is greater than 5");
}

Run it: ZincLang.exe hello.zc

📚 Module example

math.zc (library)

export add;
func add(a, b) { return a + b; }

main.zc

import math;
Print(math.add(3, 4));   // prints 7

🔗 Java interop example

import java.util.ArrayList;
var list = ArrayList();
list.add("Hello from Java");
Print(list.get(0));
