Getting Started

ZincLang is a statically‑typed, JVM‑based language with Python‑inspired syntax and seamless Java interop. To run a Zinc script:

# install ZincLang (Windows .exe or build from source)
ZincLang.exe script.zc

Or start the REPL: ZincLang.exe (no arguments).

Variables and Types

Variables are declared with a type, then name, optionally initialised.

int x = 10;
float pi = 3.14;
string name = "Zinc";
char letter = 'A';
bool flag = True;

Types: int, float, string, char, bool, void (function return only)

I/O

Print("Hello world");
string name = Input("What is your name? ");
Print("Hello, " + name);

Control Flow

if / else

int x = 10;
if (x > 5) {
    Print("big");
} else if (x == 5) {
    Print("equal");
} else {
    Print("small");
}

while loop

int i = 0;
while (i < 3) {
    Print(i);
    i = i + 1;
}

for loop

for (int i = 0; i < 5; i = i + 1) {
    Print("i = " + i);
}

break and continue

for (int i = 0; i < 10; i = i + 1) {
    if (i == 2) continue;
    if (i == 5) break;
    Print(i);
}

Functions

ZincLang supports two syntaxes: with func (return type optional) or with explicit return type (int/void).

func style

func add(a, b) {
    return a + b;
}
int result = add(3, 4);

Explicit return type

int multiply(int a, int b) {
    return a * b;
}
void sayHello() {
    Print("Hello");
}

Modules (Import/Export)

Create a module file, e.g., math.zc:

func add(a, b) { return a + b; }
func sub(a, b) { return a - b; }
export add;
export sub;

Use it in another script:

import math;
Print(math.add(5, 3));   // 8

You can also import Java classes directly:

import java.util.ArrayList;
var list = ArrayList();
list.add("Hello");
Print(list.get(0));

Classes

class Point {
    int x, y;
    void init(int x, int y) {
        this.x = x;
        this.y = y;
    }
    int getX() { return x; }
}

class Point3D extends Point {
    int z;
    void init(int x, int y, int z) {
        super.init(x, y);
        this.z = z;
    }
}

Call methods using @class.method() syntax (dynamic dispatch):

var p = Point();
@p.init(1, 2);
Print(p.getX());

Logical Operators

if (x and y) { ... }
if (x or y) { ... }
if (not x) { ... }

Error Handling

Currently ZincLang uses runtime error reporting with line numbers. Planned: try/catch blocks.

Java Interoperability

Any Java class can be imported and used as if it were a Zinc module:

import java.io.File;
var f = File("test.txt");
Print(f.getName());

import java.util.HashMap;
var map = HashMap();
map.put("key", 42);
Print(map.get("key"));

Java methods and constructors work as expected. Returned objects are wrapped as JavaInstance and support method calls.

Command‑line Interface

ZincLang.exe script.zc         # run script
ZincLang.exe                    # start REPL
💡 Tip: Use the lib/ folder or ZINC_PATH environment variable to store reusable modules globally.
